Referência: [`planning/milestones/M2-PANDORA.md`](../planning/milestones/M2-PANDORA.md) (linhas 419–429).

| Critério | Como validar | Estado |
|----------|----------------|--------|
| Neo4j em container | `docker compose up -d neo4j` + `./scripts/neo4j-apply-schema.sh` | ✅ |
| Pandora via Bolt | **Produção:** `neo4rs` em `PandoraClient`. **Nativo:** `pandora::bolt::ConnectionPool` (mock + testes C++) | ✅ (dual-path) |

| Testes integração | Rust: `pandora_neo4j_integration`, `pandora_mimi_integration`, `m2_acceptance`. C++: `ctest -R neo4j` | ✅ |
| State persistence | `save_mimi_checkpoint` / `apply_mimi_checkpoint`; loop `PandoraFlushLoop::spawn_with_checkpoint` | ✅ |
| Docs + benchmarks | Este ficheiro, `M2.2`–`M2.6`, `cargo bench` com `MIMI_BENCH_NEO4J=1` | ✅ |

## Comandos rápidos

```bash
# Offline (CI-friendly)
cargo test -p mimi-core m2_acceptance
cargo test -p mimi-core acceptance_hit_rate
cargo test -p mimi-core --test pandora_mimi_integration

# Com Neo4j
docker compose up -d neo4j && ./scripts/neo4j-apply-schema.sh
export NEO4J_URI=bolt://localhost:7687 NEO4J_PASSWORD=mimi-password
cargo test -p mimi-core --test pandora_neo4j_integration -- --ignored

# Latência
MIMI_BENCH_NEO4J=1 cargo bench -p mimi-core --bench pandora_neo4j_benchmarks

# C++
cd crates/pandora-memory/build && ctest -R neo4j_integration
NEO4J_INTEGRATION=1 ctest -R neo4j_integration
```
