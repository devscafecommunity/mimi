# M2.2 — Heatmap & Neo4j Persistence

## Components

| Layer | Location | Role |
|-------|----------|------|
| L1 LRU cache | `crates/mimi-core/src/l1_cache.rs` | Hot `Context` records (~1000), hit/miss/eviction metrics |
| L1 heatmap | `crates/mimi-core/src/heatmap.rs` | In-memory decay \(T = T_0 e^{-\lambda \cdot age}\) |
| L1 (C++) | `crates/pandora-memory/` heatmap + `LRUCache` | Same decay + native LRU |
| L2 graph | `PandoraClient` + Neo4j | `Context` nodes: `heat`, `last_accessed`, `access_count` |

## PandoraClient API

```rust
let pandora = PandoraClient::new().await?; // NEO4J_* env, fallback in-memory

pandora.touch_context("ctx:session-1", Some("User session")).await?;
let hot = pandora.hot_contexts(50).await?;
let written = pandora.flush_heatmap().await?;
```

- **`touch_context`**: updates L1 heatmap; if Bolt is available, `MERGE` on `:Context` and increments `access_count`.
- **`flush_heatmap`**: writes all L1 nodes to Neo4j (batch persist).
- **`hot_contexts`**: merges L1 hot nodes with Neo4j rows, re-applies decay on read.
- **`get_context`**: L1 LRU → Neo4j → heatmap fallback; populates cache on hit.
- **`l1_cache_stats()`**: `hits`, `misses`, `evictions` (also via `mimi debug memory-stats`).

## Health monitor integration

Healthy metrics call `touch_context` for `component:{name}` so component activity stays warm in the graph.

## M2.2.4 — Query interface & CLI

| API | Description |
|-----|-------------|
| `get_hot_nodes(min_heat, limit)` | Filtered hot contexts |
| `get_by_temperature_range(min, max, limit)` | Heat band filter |
| `search_contexts(needle, limit)` | Label/id substring search (Neo4j) |
| `expand_context_bfs(root_id, max_hops, limit)` | Graph BFS over REFERENCES/HAS/DEPENDS_ON |
| `resolve_context_for_query(query, limit, max_hops)` | Hot + BFS bundle for LLM injection |

CLI:

```bash
cargo run -p mimi-cli -- query "How does MiMi memory work?" --include-context --limit 10
```

With `--include-context`, Pandora builds `system_context` for Ollama Cloud; JSON output includes a `context` object.
