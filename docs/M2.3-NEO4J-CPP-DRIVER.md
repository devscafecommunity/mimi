# M2.3 — Neo4j Bolt driver (C++)

## M2.3.1 Driver selection

| Option | Verdict |
|--------|---------|
| **[neo4j-cpp-driver](https://github.com/neo4j/neo4j-cpp-driver)** (official) | **Selected** — Bolt 4.x, pooling, transactions, parameterized queries |
| libneo4j-client | Lower-level C API; more glue code for MiMi |

**Strategy:** implement the Pandora API against `pandora::bolt::ConnectionPool` in `crates/pandora-memory/`. The current build uses a **mock Bolt backend** (no external driver required for CI). Enable `PANDORA_ENABLE_NEO4J_CPP` later to link the official driver behind the same interface.

## M2.3.2–M2.3.5 (in progress)

| Task | Location |
|------|----------|
| Pool + health | `include/bolt_client.hpp` — `connect`, `disconnect`, `is_healthy` |
| Query execution | `ConnectionPool::run` + `QueryResult` |
| Transactions | `ConnectionPool::begin_transaction` |
| Parameters | `validate_parameters` — every `$name` must appear in `Params` |

## Rust path

Production MiMi CLI uses **`neo4rs`** in `mimi-core::PandoraClient` today. C++ Pandora will converge on the same Cypher patterns when the native engine is wired via FFI (M2.6+).
