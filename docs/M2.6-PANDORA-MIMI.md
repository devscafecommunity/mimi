# M2.6 — Pandora integration with Mimi core

## Message types

`PandoraBusMessage` (`mimi_core::pandora_integration`, re-exported from `message`):

- `task_context_request` / `task_context_response` — intent → graph bundle
- `task_outcome` — post-execution summary for heatmap

## Task execution

```rust
use mimi_core::{execute_task_with_context, StateManager, PandoraClient, Task, TaskType};

let state = StateManager::new();
let pandora = PandoraClient::new().await?;
let task = Task::new(TaskType::Execute, "deploy api");
let summary = execute_task_with_context(&state, &pandora, task).await?;
```

`mimi exec <task>` resolves Pandora context before calling Ollama (same as `query --include-context`).

## Periodic flush (M2.6.2)

```rust
use std::sync::Arc;
use mimi_core::{flush_interval_from_env, PandoraFlushLoop, PandoraClient};

let pandora = Arc::new(PandoraClient::new().await?);
let (loop_handle, shutdown) = PandoraFlushLoop::spawn(pandora, flush_interval_from_env());
// shutdown.send(true) to stop
```

Env: `PANDORA_FLUSH_INTERVAL_SECS` (default `300`, minimum `30`).

CLI runs `flush_with_retry` after `query --include-context` and `exec`.
