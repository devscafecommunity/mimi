# M3.1 — Docker isolation & skill workers

## Goals

- Run untrusted skill code in **ephemeral containers**, not on the host.
- Default **no network** (`network_mode: none`); explicit bridges only when required.
- **Resource caps:** 256 MB RAM, 50% CPU quota per skill (configurable).
- **Audit:** every create/start/stop/kill logged (structured tracing).

## Components

| Piece | Path |
|-------|------|
| Worker image | `docker/Dockerfile.worker`, `docker/worker-entry.sh` |
| Runtime API | `crates/ryzu-runtime` (`SkillRuntime`, `ResourceLimits`) |
| Bollard backend | `ryzu-runtime` feature `docker` → `BollardSkillRuntime` |
| Tests without Docker | `MockSkillRuntime` |

## Build worker image

Run from the **repository root** (not `crates/pandora-memory/build`):

```bash
./scripts/build-worker.sh
# or:
docker build -f docker/Dockerfile.worker -t mimi-worker:latest .
```

```bash
cargo test -p ryzu-runtime
cargo test -p ryzu-runtime --features docker
cargo build -p mimi-cli --features docker-supervision
```

## CLI (Odlaguna + Ryzu)

The `mimi` binary is not on your PATH until you install it. From the repo root, use `cargo run`:

Mock runtime (default build):

```bash
cargo run -p mimi-cli -- debug skill-run --cmd echo --cmd hello
```

Real Docker (`docker-supervision` + worker image):

```bash
./scripts/build-worker.sh
cargo run -p mimi-cli --features docker-supervision -- \
  debug skill-run --image mimi-worker:latest --cmd echo --cmd hello --timeout 30
```

Optional: `cargo install --path crates/mimi-cli --features docker-supervision` then `mimi debug skill-run ...`.

Queue tasks with JSON `Task::payload`:

```json
{"image":"mimi-worker:latest","command":["echo","hi"]}
```

Handled by `execute_task_with_context` → `run_isolated_skill_supervised`.

## Example (Rust)

```rust
use ryzu_runtime::{MockSkillRuntime, ResourceLimits, SkillRunRequest};

let rt = MockSkillRuntime::new();
let handle = rt.run(SkillRunRequest {
    image: "mimi-worker:latest".into(),
    command: vec!["echo".into(), "hello".into()],
    limits: ResourceLimits::skill_default(),
    network_isolated: true,
    timeout_ms: 30_000,
}).await?;
```

## Pool & restart (M3.1.3)

- `SkillContainerPool` — limits concurrent skill containers (default 8).
- `RestartPolicy` + `BollardSkillRuntime::run_managed` — exponential backoff on start/run failures (not on timeout / resource kill).
