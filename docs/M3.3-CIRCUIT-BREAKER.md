# M3.3 — Circuit breaker

## State machine

Implemented in `mimi_core::state_machine::CircuitBreaker` (CLOSED → OPEN → HALF_OPEN).

## Guard helper

`with_circuit_breaker` (`circuit_guard.rs`) wraps Pandora/AI calls in the CLI and records failures; when OPEN, returns fallback and increments **fallback** metrics.

## Metrics (M3.3.4)

`breaker.snapshot()` returns:

| Field | Meaning |
|-------|---------|
| `successful_calls` | Operations that completed OK |
| `failed_calls` | Recorded failures |
| `fallback_calls` | OPEN rejections (fallback used) |
| `opened_count` | Times the circuit opened |
| `half_open_probes` | Transitions to half-open |
| `total_open_ms` | Cumulative time spent OPEN |
| `currently_open_ms` | If OPEN now, elapsed since open |

Example:

```rust
let breaker = CircuitBreaker::new(3, Duration::from_secs(30));
let snap = breaker.snapshot();
println!("{}", serde_json::to_string(&snap)?);
```

## Shared breakers (M3.3.2)

`mimi_core::circuit_breakers()` returns process-wide Pandora + AI breakers used by `mimi exec` and `mimi query`.

## Fallbacks

| Path | OPEN / failure behavior |
|------|-------------------------|
| Pandora | `pandora_context_with_fallback` → `resolve_context_l1_fallback` (L1 hot snapshot) |
| AI | `invoke_ai_with_fallback` → next healthy adapter in `AdapterRegistry`, else static message |

```bash
cargo run -p mimi-cli -- debug circuit-stats
```

## Sustained OPEN alerts (M3.3.4)

When a breaker stays OPEN ≥ `SUSTAINED_OPEN_ALERT_MS` (30s), `circuit_breakers().check_alerts()` logs `target=circuit.alert` and increments `sustained_open_alerts` in `breaker.snapshot()`. Called after `exec`/`query` and from `debug circuit-stats`.
